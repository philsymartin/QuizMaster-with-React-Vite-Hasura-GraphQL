## **OVERVIEW**

The Online Quiz Platform serves as a candidate-focused alternative to traditional proctoring and assessment tools. Instead of monitoring candidates, the platform empowers them to prepare, improve, and track their skills through interactive quizzes, real-time feedback, and performance analytics.

## **KEY FEATURES**

- **Quizzes with multiple-choice questions:** Take interactive quizzes.
- **Score tracking:** View scores of completed quizzes.
- **Real-time leaderboards:** Track rankings dynamically.
- **Dark and light mode:** Users can switch between themes.
- **Admin panel:** Manage quizzes and users.
- **Performance analytics:** Get insights into quiz performance.
- **Live user engagement tracking:** Monitor active users in real time.
- **Sentiment analysis & keyword extraction:** Analyze feedback from quizzes.

## **TECHNOLOGIES USED**

### **Client-side (Frontend)**

- React + Vite (TypeScript
- Tailwind CSS
- Apollo Client
- Redux Saga & Redux Toolkit
- React Router DOM
- GraphQL-WS
- Liveblocks

### **Server-side (Backend)**

- Node.js + Express
- Hasura
- JWT Authentication & Authorization
- CORS
- Axios

### **Database**

- PostgreSQL

### **Testing**

- Jest, React Testing Library.

## **APPLICATION FLOW**

### **User Flow (Quiz Taker)**

- User Registration & Authentication
- Login & Dashboard Access
- Browsing & Selecting a Quiz
- Attempting a Quiz
- Submitting the Quiz & Viewing Results
- Add feedback to the Quiz they attempted

### **Admin Flow**

- Admin Login and dashboard access
- Managing Users
- Managing Quizzes
- Viewing Analytics
